# NOTICE

## Provenance

STAS is an **independent, from-scratch JavaScript re-implementation** that follows
the *behaviour* of the original STOS BASIC sources (used as a specification
only). This repository ships **no original 68000 binary, ROM, or copyrighted
STOS asset**.
